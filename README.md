# Rahul — Chennai Street & Documentary Photography

> *“My camera is my language. Chennai is my story. Photography is my forever love.”*

A street and documentary photography portfolio and interactive Darkroom Studio celebrating Chennai’s fish markets, dawn auctions, coastlines, night streets, and human moments behind the shutter.

---

## Features

- **Tactile Camera Viewfinder**: Optical rangefinder chassis with exposure meter, rule-of-thirds grid, focus reticle, and mechanical shutter sound.
- **Interactive Darkroom Studio**: Live non-destructive photo grading with film stock simulations (Kodak Portra 400, Ilford HP5 Plus, CineStill 800T, Chennai Golden Hour), dynamic RGB histogram, before/after split screen, and fine adjustment sliders.
- **Curated Favorites & Likes**: Save favorite frames to a curated reel with persistent local storage and heart animations.
- **Editorial & Contact Sheet Modes**: Browse the master archives either as an editorial story wall or a 35mm negative contact sheet roll.
- **Synthesized Audio Feedback**: Native Web Audio API camera shutter and dial click sound effects with a quick mute toggle.

---

## Local Development

Ensure you have **Node.js** (v20+ recommended) and **npm** installed.

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit [http://localhost:8080/](http://localhost:8080/) (or the assigned port) in your browser.

## Tech Stack

- **Framework**: TanStack Start / React 19

- **Styling**: Tailwind CSS v4 & Lucide Icons
- **Audio**: Web Audio API
- **Build Tool**: Vite
